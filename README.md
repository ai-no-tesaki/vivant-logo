# VIVANT風 ロゴアニメーション生成器

好きな文字列を入れると、重なった状態から左右に広がりながら浮かび上がる赤いロゴアニメーションになる。
文字は奥行きを持って重なっていて、上にある文字の影が下の文字の上にだけ落ちる。
PNG と WebM で書き出せる。

**→ https://ai-no-tesaki.github.io/vivant-logo/**

## タイムライン

展開率 `p` と透明度は独立に動く。`t` は 0〜100 の内部時間で、再生は t=20 から始まる。

| t | 起きること |
|---|---|
| 0 → 20 | 透明度100%（何も映らない）。この間も等速で広がっている |
| 20 → 100 | 透明度が 100% → 0% へ等速で変化 |
| 0 → 70 | 移動は等速 |
| 70 → 100 | 減速しながら停止 |
| 80 → 100 | 影が透明度100%へ |

再生尺の既定は 1.6 秒。何も映らない t=0→20 を飛ばしているだけなので、
移動の速さは「t=0→100 を 2.0 秒」と同じ 50 t/秒。

### 減速

t≤70 は速度 `v0` の等速、t>70 は `v0·(1−u²)`（`u` は減速区間の進捗 0→1）。
減速度が `2·v0·u` なので終端に近いほど強くかかり、t=100 でちょうど速度 0 になる。
減速区間で稼げる距離が等速時の 2/3 に減る分 `v0 = 1/(70 + 30·⅔) = 1/90` と上げてあり、
最終位置は等速のまま走った場合と一致する。

## 重なりと影

中央の文字が最下層、両端が最上層。文字数が偶数なら中央2文字のうち後ろが下。
遠近による大きさの変化はなく、奥行きは重なり順と影だけで表現している。

影は字面に接する側が透明度0%、外縁が透明度100%の黒のグラデーションで、幅は線幅の 0.8 倍。
線幅は文字を実際にラスタライズして走査線上の連続ピクセル長から実測している（190px の VIVANT で 32px）。
グラデーションは同心のストロークを外→内に重ね、合成後の α が線形になるよう各段の α を逆算して作る。
影は「すでに描いた文字」のマスクで切り抜くので、背景には落ちず下のレイヤーの文字の上にだけ乗る。

ロゴ全体は一度オフスクリーンに不透明で合成してからフェードさせている。
文字ごとに透明度を掛けると、重なっている区間だけ濃く見えてしまうため。

## 操作

| 操作 | 動作 |
|---|---|
| Space / 再生ボタン | 再生・停止 |
| タイムライン | 任意の t を確認（t=0 から触れる） |
| 現在フレームPNG | いま表示している t を書き出す |
| 完成形PNG | t=100 を書き出す |
| 動画を書き出す | WebM（VP9／VP8、Chrome・Edge） |

フォントは Archivo Black・横比率 0.75 固定。文字色・背景色・サイズ・字間・影・出力解像度は変更できる。

依存ライブラリなしの 1 ファイル。`index.html` を開くだけで動く（フォントのみ Google Fonts から読む）。
